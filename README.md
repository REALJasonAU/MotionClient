# Motion

**MOVE FASTER.** Motion is a Minecraft launcher and client for Windows, built for performance and a clean, modern interface.

Download `Motion_x.y.z_x64-setup.exe` from the [latest release](https://github.com/REALJasonAU/MotionClient/releases/latest) and run it. Motion keeps itself up to date. Running a newer setup file also updates an existing install.
